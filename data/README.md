# Data

This project uses the **House Price Prediction Challenge** dataset (India), which is **not included in this repository**.

The dataset is licensed under the GNU GPL v2 by its original authors, so it is not redistributed here.

## How to get it
1. Download `Train.csv` from the Kaggle dataset page: https://www.kaggle.com/datasets/anmolkumar/house-price-prediction-challenge
2. Rename it to `train.csv` and place it in this folder, so the path is `data/train.csv`.

It should have 29,451 rows and 12 columns. The notebook in `notebooks/` reads it from this location.
